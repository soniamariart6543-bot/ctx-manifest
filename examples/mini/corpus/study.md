# 学习笔记（示例 · 长尾层）

> 第三个 `lookup` 例子：命中「学习 / 笔记 / 复习 / 考试 / 概念」时才给一行摘要。
> 长尾层的价值在于：它平时**不占预算**，但真问到时不至于一片空白。

## 记笔记的顺序

1. **概念**：一句话说清它是什么（不许用术语解释术语）
2. **例子**：最小可运行的例子，不是「比如生活中……」
3. **反例**：什么情况下它不成立 —— 这一条最容易被跳过，也最有用
4. **复述**：合上笔记，用自己的话写三行

四步里缺第 3、4 步的笔记，考试前会发现等于没记。

## 复习节奏

| 间隔 | 做什么 |
|---|---|
| 当天 | 复述一遍，标出卡壳处 |
| 第 3 天 | 只看卡壳处 |
| 第 7 天 | 做一道综合题 |
| 第 21 天 | 讲给别人听（或写出来） |

## 判断「学会了」的判据

- 能不用笔记讲出主线和三个关键细节
- 能说出它和相邻概念的区别
- 能举一个它不适用的场景

三条都做到才算会；只做到第一条是「认识」，不是「掌握」。

## 常见坑

- 抄书不等于笔记（没有自己的话）
- 只记结论不记推导（忘了就全忘）
- 收集了十个版本的资料却一份没读完
